# HU-010 Creación de perfil de cliente

**Como** Administrador.

**Quiero** Crear el perfil de un cliente activo y asignarlo a un Abogado/Asesor responsable.

**Para** Contar con un registro completo y centralizado de cada cliente de la firma, con su Abogado/Asesor responsable asignado y su modalidad de pago definida.

## Criterios de aceptación

- El usuario ingresa al módulo de prospectos y selecciona "Ver detalle" del prospecto.
- El sistema muestra la ficha del prospecto con la opción de convertir a cliente.
- El usuario selecciona convertir a cliente y el sistema precarga los datos del prospecto en el formulario.
- El usuario completa los campos faltantes: modalidad de pago y Abogado/Asesor responsable.
- El sistema valida los datos y guarda el perfil como cliente activo.
- Los cambios se registran en la bitácora de auditoría.
